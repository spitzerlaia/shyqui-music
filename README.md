# Shyqui Music

[![Latest Release](https://img.shields.io/github/v/release/spitzerlaia/shyqui-music?label=latest%20release)](https://github.com/spitzerlaia/shyqui-music/releases/latest)

Shyqui Music is a lightweight music player built with [Tauri](https://tauri.app/) and integrated YouTube playback. It started as a hobby project with a simple goal: provide a free, ad-free way to listen to music, create playlists, and enjoy content from YouTube.

> Shyqui Music is not affiliated with, endorsed by, or sponsored by YouTube or Google.

## Features

- Free and ad-free playback.
- Listen to music from YouTube.
- Create and manage playlists.
- Lightweight and optimized for low resource usage.
- Desktop-first experience.

## Performance

- Approximately 5 MB of RAM usage.
- Very low GPU usage.
- Built with optimization in mind.

## Platforms

- **Desktop:** available now.
- **Android:** APK release planned.
