# Shyqui Music

**A lightweight, ad-free desktop music player powered by YouTube.**

[![Latest Release](https://img.shields.io/github/v/release/spitzerlaia/shyqui-music?label=latest%20release)](https://github.com/spitzerlaia/shyqui-music/releases/latest)

Shyqui Music is a lightweight music player built with [Tauri](https://tauri.app/) and integrated YouTube playback. It started as a hobby project with a simple goal: provide a free, ad-free way to listen to music, manage playlists, and enjoy YouTube content through a desktop application.

> Shyqui Music is not affiliated with, endorsed by, or sponsored by YouTube or Google.

## Features

- **Ad-free playback** — Listen to music without in-app advertisements.
- **YouTube integration** — Play YouTube videos directly in the application.
- **Playlist support** — Create and manage playlists.
- **Queue management** — Organize and edit your playback queue.
- **Playback history** — Keep track of previously played content.
- **Playback recovery** — Resume playback from where you left off.
- **Customizable themes** — Personalize the application's theme colors.
- **Lightweight design** — Built with Tauri for a desktop-focused experience.
